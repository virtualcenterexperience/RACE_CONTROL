VCE ESPORT V12.1 — AVATAR DANS LE MENU

Sur toutes les pages, un pilote connecté voit son avatar rond à droite du menu, près de son nom. Cliquer sur le rond ou le petit crayon permet d’importer une nouvelle photo JPG/PNG/WebP (6 Mo max). Elle est réduite à 320 px puis enregistrée dans le navigateur sous la clé vce_photo_<id>. L’avatar de l’accueil se met aussi à jour.

Remplacer les fichiers du dépôt GitHub Pages par ceux de cette archive. Pour une mise à jour minimale, remplacer seulement vce-v11-nav.js, vce-v11-avatar.js et vce-v11.css.

Limite : le stockage est local au navigateur, pas partagé entre les appareils.
