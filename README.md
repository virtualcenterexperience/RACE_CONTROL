# VCE Performance Center V15

Trois pages séparées : index.html, entrainement.html, strategie.html.

Nouveautés :
- 160 situations diagnostiques (20 ressentis x 8 familles de voitures), avec hypothèses, conseils, questions et exercices
- Module diagnostic filtrable par voiture et phase
- Chat de débrief enrichi par ces scénarios; assistant local à règles, **pas une IA générative**
- Intégration de `base_lmu_references.json`: 990 combinaisons, 49 temps communautaires présents, non records mondiaux
- Sélecteur catégorie / voiture / circuit et bouton pour renseigner automatiquement l’objectif de séance
- Références indisponibles correctement signalées, aucun chrono inventé

Installation : déposer les quatre fichiers HTML/JSON à la racine GitHub Pages, conserver le dossier `sauvegardes`. Pour accéder au JSON, servir les fichiers par un serveur HTTP (GitHub Pages) plutôt qu’ouvrir entrainement.html en file://.

Les indications de réglage (freinage, pluie, pression, ABS) sont des hypothèses à tester et à faire valider par un coach, non des réglages universels.
