# VCE ESPORT V32 — mise à jour visuelle V20

## Installation GitHub Pages
Décompresser puis copier **le contenu** du ZIP directement à la racine du dépôt `RACE_CONTROL` (index.html doit rester à la racine). Faire un commit et un push sur `main`, puis Ctrl+F5.

## Changements
- Navigation unique : suppression du menu injecté en doublon, affichage d’un menu unique sur les pages historiques.
- Profil : accès Changer de profil et Déconnexion dans la barre unifiée.
- Accueil : retrait du bouton obsolète Tableau de bord V18, accès Dashboard dans le menu.
- Classement : bouton de déploiement Top 5 / complet dans le profil lorsque le classement est rendu.
- Entraînement : Coach, Sans coach, Coach IRL et comparaison des chronos conservés.
- TEAM : calendrier, lineup, affiches, résultats et panneau Staff conservés, sans cartes d’introduction redondantes.
- CARS : bibliothèque technique existante avec recherche, filtres et une fiche ouverte.
- Stratégie et Dashboard : modules existants conservés.

## Limites
Stockage local par navigateur : les données ne se synchronisent pas entre ordinateurs. Les courbes de télémétrie ne sont pas créées sans données réelles. Sauvegarder les fichiers JSON avant de remplacer l’ancienne version. Ne pas supprimer le dossier `sauvegardes` sans copie.
