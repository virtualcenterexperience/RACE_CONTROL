# VCE ESPORT — V20 Design Refresh (Track Titan × VCE Racing)

Cette édition est construite directement sur **VCE ESPORT TRAINING PRO V20**. Elle ne remplace pas les scripts métier.

## Modifications
- Palette unifiée bleu nuit, rouge VCE, bleu technique, gris carbone et blanc.
- Navigation, panneaux, champs, boutons, tableaux et cartes harmonisés.
- Index, Entraînement, TEAM, Stratégie et Dashboard ajustés sur ordinateur et mobile.
- Entraînement : les outils secondaires de l'ancien portail peuvent être affichés/masqués pour désencombrer la page ; les outils d'origine restent présents.
- Deux nouveaux fichiers seulement : `vce-design-refresh-v20.css` et `vce-design-refresh-v20.js`.

## Installer sur GitHub Pages
1. Sauvegarder le dépôt et exporter les données locales avant modification.
2. Décompresser l'archive.
3. Copier **tout le contenu** du dossier à la racine de `RACE_CONTROL` (pas le dossier lui-même).
4. Faire Commit/Push puis Ctrl+F5.

## Limites
Les fonctions d'origine V20 restent telles quelles, avec leurs éventuelles limites. Aucun nouveau module ou stockage distant n'a été ajouté. Les vérifications statiques ne remplacent pas un test interactif complet sur navigateur.
