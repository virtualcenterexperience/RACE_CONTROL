VCE ESPORT — DESIGN UNIFIÉ V8

INSTALLATION : décompresser tous les fichiers dans la racine du dépôt GitHub Pages /RACE_CONTROL/ et conserver vos fichiers de sauvegarde.

NOUVEAUTÉS :
- Charte noir graphite, gris anthracite et vert néon appliquée aux cinq pages.
- Un seul menu commun (Accueil / Entraînements / Stratégies / Cars / Diagnostics), adaptatif sur mobile.
- Page de sélection Individuel / Groupe / Accès Coachs conservée avant d’afficher les outils.
- Profil actif et bouton de déconnexion dans la barre commune.
- Cartes et champs harmonisés, animations d’apparition, transition de page, bouton retour en haut.
- Module de diagnostic interactif V7 activé (curseurs intensité, fréquence, adhérence et retour d’exercice).
- Outils Race Control, fiches voitures, suivi des séances et classements existants conservés.

IMPORTANT : le site GitHub Pages reste statique. Les données sont locales au navigateur et le mot de passe coach côté client ne garantit pas une sécurité réelle. La télémétrie anti-triche et la synchronisation multi-appareils nécessitent un serveur.
