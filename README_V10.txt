VCE ESPORT PERFORMANCE CENTER V10

Installation : décompresser tout le dossier à la racine du dépôt GitHub Pages RACE_CONTROL.

Accueil : uniquement 3 profils avant connexion (GROUPE / PILOTES / STAFF). Après connexion : circuit animé, classement et structure VCE ESPORT. Le menu apparaît seulement après sélection.

STAFF : mot de passe train, protégé uniquement dans le navigateur. Staff peut créer un pilote dans Gestion Staff, et valider les entraînements dans Entraînements.

PILOTES : choix du profil, photo de profil, entraînements avec ou sans coach, base 1000 solutions, bibliothèque et fiche Cars. Photos compressées et sauvegardées dans le navigateur. Exporter photo et déposer le fichier dans medias/ du dépôt pour le publier. L'option Enregistrer dans medias peut écrire dans un dossier local choisi via Chromium ; cela ne publie pas sur GitHub.

ENDURANCES : accès groupe à Stratégies / Race Control. La fin d'une endurance donne 10 points par pilote participant, après validation par le Staff depuis Stratégies. Une même course (nom + date) ne peut pas être créditée deux fois au même pilote sur cet appareil.

IMPORTANT : GitHub Pages est statique. Les données de pilotes, validations, points, photos et récompenses sont locales à chaque navigateur, pas synchronisées entre les appareils. Le mot de passe train n'est pas une authentification serveur et ne protège pas réellement les données. Pour une synchronisation et des permissions fiables, utiliser un backend (par ex. Supabase ou Firebase) avec comptes Staff sécurisés.

Les tracés animés sont schématiques, non des cartes officielles précises.
