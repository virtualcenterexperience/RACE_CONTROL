VCE ESPORT V17 — TEAM MANAGER + UI

- TEAM visible pour tous les profils; accès manager par mot de passe train.
- Manager peut ajouter, modifier et supprimer courses, lineups et résultats (confirmations de suppression déjà présentes).
- Le mode STAFF déjà actif conserve ses droits. Le bouton Verrouiller ferme uniquement la session Manager.
- Fond automobile issu de l’image fournie, recadrée pour mettre en avant les pilotes.
- Couleurs rouge, bleu, blanc appliquées sur toutes les pages via vce-theme-v17.css.
- Entraînements : 3 choix immédiats; outils complémentaires repliables.
- Animations légères et réduction des mouvements respectée.

IMPORTANT : Le mot de passe côté navigateur ne constitue PAS une sécurité réelle.
Les données sont en localStorage, donc pas synchronisées entre appareils et modifiables dans les outils développeur.
Le webhook Discord en clair dans team.html est PUBLIC. Il faut le remplacer par un relais serveur pour protéger les publications.
